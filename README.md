# animals_quiz
Animals Quiz with pictures (engine)
может быть использована для создания собственных викторин, для этого надо загрузить на своем ПК картинки в images
и отредактировать layout.json

Доступна по адресу
https://alexander-a-kladov.github.io/animals_quiz/index.html
- На смартфоне лучше играть в горизонтальном режиме

Для запуска локально на ПК
./start_httpd.sh
в браузере открыть http://localhost:8080/index.html


Скрипты для редактирования Викторин

Генератор шаблонных (для последующего редактирования) layout.json на основе файлов answer.txt, содержащий ответы на вопросы разделенные по карточкам, 
запуск в браузере layout_gen/layout_generator.html


Автоматизированное получение координат точек на изображениях из каталога images,

./scrcoord.py - копирует координаты точки при нажатии на картинке мышкой и размещает туда графический элемент для наглядности,
координаты помещаются в буфер обмена в формате "x": %d, "y": %d - для того чтобы напрямую вставлять их в layout.json

Редактор текстовый с возможностью вставки координат, автоматическим поиском ближайшей снизу от курсора записи координат и заменой их
на координаты из буфера обмена, в остальном приметивен и хуже обычного текстового редактора

./texteditor_tmpl.py

в файле templates.txt варианты шаблонов для поиска в тексте, поддерживает только два вида шаблонов "x": %d, "y": %d и "%s": %d
