# animals_quiz
Animals Quiz with pictures (engine)
может быть использована для создания собственных викторин, для этого надо загрузить на своем ПК картинки в images
и отредактировать layout.json

Доступна по адресу
https://alexander-a-kladov.github.io/animals_quiz/index.html
- На смартфоне лучше играть в горизонтальном режиме

Для запуска локально на ПК
./start_httpd.sh
в браузере открыть http://localhost:8080/index.html
